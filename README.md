# NewSupportManager
SCP: Classified Site plugin

Данный плагин заменяет существующий в игре SupportManager на новый. Отличия:
- Добавлена система тикетов для МОГ и ПХ. Изначально равны 50 на 50 (сумма тикетов всегда равна 100). Прибывает та команда, у которой больше тикетов (если равны, рандом). Тикеты зарабатываются командой ПХ или МОГ при убийстве (2 тикета за убийство SCP (кроме SCP-049-2), в остальных случаях - 1), побеге класса-Д или учёного (если сбежали связанными, тикеты прибавляются противоположной команде). Тикеты убавляются у команды, которая прибывает в комплекс. Таким образом, сделать так, чтобы прибыло 2 одинаковых отряда подряд, очень сложно;
- Если SCP ловят кого-то, таймер немного увеличивается;
- Добавлен текст (виден только спектаторам), который показывает время до поддержки и тикеты;
- Если слишком много спектаторов и слишком мало живых игроков, причём остались только 2 команды, таймер ускоряется, чтобы раунд не затягивался и не было скучно (**пока-что это работает только в lua версии плагина**);
- Если установлен плагин **SerpentsHand**, то в некоторых случаях может прибыть отряд Длани Змея. Их отряд меньше, чем отряд ПХ/МОГ. Причём время до прибытия следующего отряда в 2 раза меньше, чем обычно. Отряд прибывает, если МОГ/ПХ плохо работали после своего прибытия - нанесли мало урона по SCP. Примечание: отряд ДЗ никогда не прибывает первым, не бывает 2 отряда ДЗ подряд, ДЗ не прибудет, если нет никаких SCP.

 Некоторые параметры можно менять через конфиг:
 - **minimum_time_to_spawn** - минимальное время, за которое может прибыть отряд;
 - **maximum_time_to_spawn** - максимальное время, за которое может прибыть отряд.
