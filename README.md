# NewSupportManager (v3.2)
SCP: Classified Site plugin

Данный плагин заменяет существующий в игре SupportManager на новый. Отличия:
- Добавлена система шансов для МОГ и ПХ. Изначально равны 50 на 50 (сумма всегда равна 100). Шансы убавляются у команды, которая прибывает в комплекс;
- Добавлен текст (виден только спектаторам), который показывает время до поддержки, шансы, количество активированных генераторов и прибывших отрядов;
- Если слишком много спектаторов и слишком мало живых игроков, причём остались только 2 команды, то таймер ускоряется, чтобы раунд не затягивался и не было скучно;
- Если установлен плагин **SerpentsHand**, то в некоторых случаях может прибыть отряд Длани Змея. Их отряд меньше, чем отряд ПХ/МОГ. Отряд прибывает, если МОГ/ПХ плохо работали после своего прибытия - не убили ни одного сцп и не активировали ни одного генератора. Примечание: отряд ДЗ никогда не прибывает первым, не бывает 2 отряда ДЗ подряд, ДЗ не прибудет, если нет никаких SCP.

 Некоторые параметры можно менять через конфиг:
 - **minimum_time_to_spawn** - минимальное время, за которое может прибыть отряд;
 - **maximum_time_to_spawn** - максимальное время, за которое может прибыть отряд.
